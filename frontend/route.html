🎓 Algorithm & Implementation Details (B.E. Computer Science)

Data Structure: The road network is modeled as an adjacency list graph G = (V, E) where vertices V represent junctions and weighted edges E represent bidirectional roads with distance weights w(u, v) ≥ 0 in kilometers.

Algorithm Complexity: Dijkstra's algorithm uses Java's PriorityQueue<NodeDistance> (Min-Heap), achieving an optimal time complexity of O((|V| + |E|) log |V|).

Haversine vs Dijkstra: NourishNet strictly distinguishes straight-line geodesic distance (Haversine formula used for the 15-km transport policy rule) from real road routing (Dijkstra algorithm on the road graph), ensuring authentic transit distance calculations.
